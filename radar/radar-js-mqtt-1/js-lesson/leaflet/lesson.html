Хичээл 04 — Leaflet

Газрын зураг, tile provider, давхарга

Leaflet нь хөнгөн, plugin-фriendly JS газрын зургийн сан. Энэ апп-д орон нутгийн хуулбарыг leaflet/ фолдерт ашиглаж байна (интернетгүй бүтээхэд бэлэн).

1. Зургийг үүсгэх

const map = L.map('map', { zoomControl: false, attributionControl: false })
  .setView([state.center.lat, state.center.lon], 14);

L.map('map') нь <div id="map">-г зураг болгоно. setView нь төв ба масштабыг тогтооно.

2. Tile provider — газрын зурагны хавтан

Хавтангууд (tiles) нь гадаад тусгаарлагдсан url-аас ачаалагддаг. Апп хэд хэдэн provider-ийг тогтмол хадгалдаг:

const PROVIDER_TEMPLATES = {
  osm:      { url: 'https://tile.openstreetmap.org/{z}/{x}/{y}.png', max: 19, attr: osmAttrib },
  carto:    { url: 'https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png', max: 20 },
  opentop:  { url: 'https://{s}.tile.opentopomap.org/{z}/{x}/{y}.png', max: 17 },
  esri:     { url: 'https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}', max: 18 },
};

Providether-ий шилжүүлэх:

function applyMapProvider(name) {
  if (state.tileLayer) map.removeLayer(state.tileLayer);
  const t = PROVIDER_TEMPLATES[name];
  state.tileLayer = L.tileLayer(t.url, { attribution: t.attr, maxZoom: t.max, subdomains: t.subdomains })
    .addTo(map);
}

Google-ий хувьд leaflet/GoogleMutant.js plugin ашиглана — Google-ийн API key шаардлагатай; үгүй бол osm руу буцаж авдаг.

3. Тэмдэглэгээ, тойрог, шугам

Апп илрүүлэлтийг L.circleMarker (жижиг цэг), роботыг L.circle (хүрээ) + шугамаар зурдаг:

const blip = L.circleMarker([lat, lon], {
  radius: 5, color: base, fillColor: base, fillOpacity: 0.9
}).bindPopup(`<b>${name}</b>`).addTo(map);

const rangeCircle = L.circle([r.lat, r.lon], {
  radius: r.rangeM, color: base, weight: 1, fill: false
});

4. Төвийн синк

Хэрэглэгч зургийг сульдаавал төвийг мэдээж state.center-т шинэчлэх хэрэгтэй:

map.on('moveend', function() {
  const c = map.getCenter();
  state.center = { lat: c.lat, lon: c.lng };
  // инпут талбаруудыг дахин дүүргэх
  document.getElementById('centerLat').value = c.lat.toFixed(6);
  document.getElementById('centerLon').value = c.lng.toFixed(6);
});

5. Роботын давхаргын удирдлага

Робот бүр өөрийн L.layerGroup үүсгэнэ; шинэчлэлт бүрт давхаргыг устгаж, дахин үүсгэхээс зайлсхийхийн тулд зургийн "signature"-ыг хадгалан, өөрчлөгдсөн үед л дахин зурдаг:

const sig = JSON.stringify({lat:r.lat, lon:r.lon, range:r.rangeM, rings:r.rings, color:r.color, heading:r.heading, blips:r.blips});
if (r.sig !== sig) { clearRobotLayers(name); drawRobotOnMap(r); r.sig = sig; }

6. Зурагны давхраа (layering)

Радар overlay нь Leaflet давхаргын дээгүүр зурагддаг:

#radarOverlay{position:absolute;inset:0;pointer-events:none;z-index:800;}

z-index:800 нь Leaflet tile/тэмдэгний дээр, харин төвийн пиний дээр харагдана. pointer-events:none нь хэрэглэгч хулганаар зурагтай харилцах боломжийг хадгална.

Интернетгүй бол зарим provider tile ачаалахгүй — зураг саарал байх боловч радар, blip-ууд үргэлжлүүлэн харагдах болно.

Дасгал

  • PROVIDER_TEMPLATES-д шинэ provider нэм (жишээ: https://tiles.stadiamaps.com/.../).
  • Робот хүрээний өнгийг r.color-оос хамааруулан өөрчилж үз.
