Хичээл 09 — Android холбоос

Телефон: мэдрэгч, MQTT, USB serial, камер

Телефон (Android Studio төсөл android-robot-app/) эдгээрийг хийдэг:

  1. Мэдрэгч synth (GPS, батарея, accelerometer, gyroscope, heading)
  2. MQTT publish (TCP 1883) → robots/<name>/status
  3. USB OTG + usb-serial-for-android → Arduino-ийн JSON мөрийг задлах
  4. Камер: JPEG фреймүүдийг POST /cam/<name> -руу → вэб апп MJPEG-ээр харна

3. Мэдрэгч (SensorsCollector.kt)

class SensorsCollector(private val ctx: Context, private val out: SensorState) {
  private val mgr = ctx.getSystemService(Context.SENSOR_SERVICE) as SensorManager

  fun start() {
    mgr.registerListener(listener,
      mgr.getDefaultSensor(Sensor.TYPE_ACCELEROMETER),
      SensorManager.SENSOR_DELAY_UI)
    mgr.registerListener(listener,
      mgr.getDefaultSensor(Sensor.TYPE_GYROSCOPE),
      SensorManager.SENSOR_DELAY_UI)
  }
  private val listener = object : SensorEventListener {
    override fun onSensorChanged(e: SensorEvent) {
      when (e.sensor.type) {
        Sensor.TYPE_ACCELEROMETER -> { out.ax = e.values[0]; out.ay = e.values[1]; out.az = e.values[2]; }
        Sensor.TYPE_GYROSCOPE     -> { out.gx = e.values[0]; out.gy = e.values[1]; out.gz = e.values[2]; }
      }
    }
  }
}

4. GPS (LocationMonitor.kt)

fun start() {
  if (ActivityCompat.checkSelfPermission(ctx, Manifest.permission.ACCESS_FINE_LOCATION) !=
      PackageManager.PERMISSION_GRANTED) return
  locationManager.requestLocationUpdates(LocationManager.GPS_PROVIDER, 1000, 1f, listener)
}
private val listener = object : LocationListener {
  override fun onLocationChanged(l: Location) {
    out.hasLocation = true; out.lat = l.latitude; out.lon = l.longitude
    out.alt = l.altitude; out.speed = l.speed
  }
}

Heading нь accelerometer-оос тооцогдож, GPS-ээс l.bearing байвал давуугаар авдаг.

5. MQTT publish (MqttManager.kt)

fun start() {
  val opts = MqttConnectOptions().apply {
    isCleanSession = true; connectionTimeout = 10
    keepAliveInterval = 20; automaticReconnect = true
  }
  client.connect(opts)   // Background thread-д
}
fun publish(topic: String, body: String) {
  if (!client.isConnected) return
  val msg = MqttMessage(body.toByteArray()).apply { qos = 1 }
  client.publish(topic, msg)
}

MainActivity нь 1 секунд тутам үүсгэсэн JSON-ийг publish хийдэг:

val json = JSONObject().apply {
  put("name", robot)
  put("lat", state.lat); put("long", state.lon)
  put("battery", state.battery)
  put("accel", JSONArray().apply { put(state.ax); put(state.ay); put(state.az) })
  put("gyro", JSONArray().apply { put(state.gx); put(state.gy); put(state.gz) })
  ...
}
mqtt.publish("robots/$robot/status", json.toString())

6. USB serial + радар задлал

val manager = getSystemService(Context.USB_SERVICE) as UsbManager
val port = manager.deviceList.values.firstOrNull()?.let {
  UsbSerialProber.getDefaultProber().findDriver(it)?.ports?.get(0)
}
port?.open(connection)?.apply {
  setParameters(115200, 8, UsbSerialPort.STOPBITS_1, UsbSerialPort.PARITY_NONE)
  read(buffer)   // bytes → RadarFrameParser.onData()
}

Радар пакет телё ямар байгааг танихын тулд RadarFrameParser.kt Arduino-ийн JSON мөрийг барьж, onRadarReport-ээ MQTT руу Relay хийнэ.

7. Камер (CameraController.kt)

// Camera2 capture loop: frame → Bitmap JPEG → HttpURLConnection POST
thread {
  val conn = URL("http://$host:$httpPort/cam/$robot").openConnection() as HttpURLConnection
  conn.requestMethod = "POST"
  conn.doOutput = true
  conn.setRequestProperty("Content-Type", "image/jpeg")
  conn.outputStream.use { it.write(jpegBytes) }
  val code = conn.responseCode   // 200 = "ok N"
}
Android төслийг энэ pc-д build хийх боломжгүй (Android SDK байхгүй). Утас: Android Studio-г нээж, Gradle sync + Build APK. Утас болон сервер LAN дээр ижил Wi-Fi-д байх ёстой (broker IP = PC).
