Хичээл 03 — MQTT

Мэдээлэл солилцооны суурь

MQTT нь төхөөрөмж хоорондын хөнгөн, publish/subscribe загварын протокол. Төв нь брокер (энэ тохиолдолд манай mqtt-server.js). Клиентүүд брокерт холбогдож, topic руу зурвас нийтэлдэг, өөрсдийн сонирхсон topic-ийг subscribe хийдэг.

Topic tree

Topic нь / талбараар ялгагдана:

TopicХэн нийтэлдэгАгуулга
radar/detectionsгазрын станц / симуляторилрүүлсэн объект (lat, long, speed...)
robots/<name>/statusAndroid роботGPS, батарей, IMU, heading
robots/<name>/radarAndroid роботLD2415H-ийн илрүүлэлт
robots/<name>/cmdвэб апп(нөөцөд) командууд

Wildcard: robots/+/status гэдэг нь "ямар ч нэртэй робот бүрийн status" — + нь нэг түвшин. # нь бүх түвшинг хэлнэ.

Вэб аппны талд (Paho клиент)

Paho нь browser-ийн WebSocket дээр ажилладаг MQTT клиент. Аппын холболт:

state.mqttClient = new Paho.Client(host, parseInt(port), clientId);

state.mqttClient.onConnectionLost = function(resp) {
  state.mqttConnected = false;
  document.getElementById('statusDot').className = 'status-dot status-disconnected';
  document.getElementById('statusText').textContent = 'Disconnected';
  log('Connection lost: ' + (resp.errorMessage || 'unknown'));
};

state.mqttClient.onMessageArrived = function(msg) {
  const t = msg.destinationName;
  if (t.indexOf('robots/') === 0) { handleRobotMsg(t, msg.payloadString); return; }
  try { addDetection(JSON.parse(msg.payloadString)); }
  catch (e) { log('Invalid message: ' + e.message); }
};

state.mqttClient.connect({
  onSuccess: function() {
    state.mqttConnected = true;
    // гол топик + бүх роботууд:
    client.subscribe(topic);
    client.subscribe('robots/+/status');
    client.subscribe('robots/+/radar');
    ...
  }
});

Серверийн талд (aedes)

Сервер нь aedes брокер ажиллуулж, TCP (1883) болон WebSocket (8080) хоёроор хоёуланг нь хүлээн авдаг:

const aedes = require('aedes')();
const ws = require('ws');
const net = require('net');

// WebSocket дээр: HTTP серверийг upgrade хийх
const wsServer = new ws.Server({ server: httpServer });
wsServer.on('connection', socket => aedes.handle(ws.createWebSocketStream(socket)));

// TCP дээр: энгийн tcp server
const tcpServer = net.createServer(aedes.handle);

Мөн сервер брокерийн publish событыг сонсож, robots/<name>/status|radar-ыг шууд register хийгээд /api/robots-нд худалдаалдаг. Энэ нь вэб аппгүйгээр ч робот онлайнаас харах боломж.

Зурвасын формат (JSON)

Робот status жишээ:

{
  "name": "robot-1",
  "lat": 47.91856696684756, "long": 106.91779462330955,
  "alt": 1280.5, "speed": 0.2, "accuracy": 3.0, "hasLocation": true,
  "battery": 86, "charging": false, "voltage": 4.02,
  "accel": [0.1, 9.8, 0.3], "gyro": [0.01, -0.02, 0.03],
  "heading": 90.0, "ts": 1757482200000
}

Радар илрүүлэлт:

{
  "name": "robot-1", "state": 1, "dist": 420, "ena": 55,
  "targets": [ { "g": 2, "t": 0, "d": 420, "e": 55 } ],
  "ts": 1757482200000
}

state: 0=юу ч байхгүй, 1=хөдөлгөөнт, 2=тогтмол. dist=зай (cm), ena=хүч.

Туршилт (mosquitto клиент)

mosquitto_pub -h localhost -t "radar/detections" -m '{"datetime":"2026-09-10 14:30:00","lat":47.9185,"long":106.9177,"altitude":500,"speed":120,"direction":45,"object_name":"target-01"}'
mosquitto_sub -h localhost -t "robots/+/status"
WebSocket болон TCP дээрх ижил брокер: телефон (TCP) болон browser (WS) бие биенээ хардаг.

Дасгал

  • subscribe('robots/+/radar')-г салгаад ямар өөрчлөлт гарахыг ажигла.
  • Өөрийн topic alerts буцалт аддаад, аппнаас subscribe хийж тестл.
