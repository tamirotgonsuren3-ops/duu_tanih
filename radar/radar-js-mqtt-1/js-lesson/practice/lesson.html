Хичээл 10 — Дадлага

Жижиг даалгаварууд, баталгаажуулалтын арга

Энд тайлбарласан бүх зүйлийг туршиж суурь болгоорой. Өөрчлөлт бүрийн дараа F5 дарж, DevTools (F12) console-ээс алдаа байгаа эсэхийг харна уу.

Даалгавар 1 — Өөрийн MQTT топик

Сервисийн вэб апп-д шинэ топик нэм:

  1. mqtt-server.js дээр HTTP сервист бүх топикийг логдуулдаг хэсэгт aedes.on('publish') байгаа.
  2. radar.html дээр subscribe('alerts') нэмж, onMessageArrived-д alert случая хийнэ.
  3. mosquitto_pub-аар илгээж туршиж үз.

Даалгавар 2 — Үсгийн өсгөх (чиглэлийг)

Гол радарын maxRangeM утгыг 5000 хүртэл өсгөж, blip подлноет цөөн хүрээний цэгүүдэд тарааж байгаа эсэхийг хар. distToPx() урт блок-той харьцуулахыг ажигла.

Даалгавар 3 — Tile provider нэмэх

PROVIDER_TEMPLATES руу шинэ provider нэмж (жишээ: stamen-toner), applyMapProvider('name') гэж дуудаж, sidebar инпут сонголтод шинэ сонголт нэм.

Тогда газрын зургийн НҮБ-ийн хавтан ачаалж байгаа эсэхийг DevTools → Network табнаас харна уу.

Даалгавар 4 — Роботын радар өнгө

Тохиргооны модаль дээрх өнгөний picker-ийг ашиглаад r.color-ыг өөрчил. Мап + хүснэгтийн цэгүүд шууд дахин зурдаг эсэхийг хар. Код: drawRobotOnMap(r).

Даалгавар 5 — CDP (headless) тест

Хуудас алдаагүй ажиллаж байгаа эсэхийг терминалаас шалгана:

msedge --headless=new --remote-debugging-port=9222 --user-data-dir=/tmp/edge-prof http://localhost:8080/radar.html

# node script:
const WebSocket = require('ws');
const list = await fetch('http://localhost:9222/json/list').then(r=>r.json());
const ws = new WebSocket(list.find(t=>t.type==='page').webSocketDebuggerUrl);
// Runtime.evaluate: document.getElementById('statusText').textContent

Энэ нь вэб аппны хамгийн хурдан automашia тест юм: пробел Console руу console.log алдааг цуглуул.

Даалгавар 6 — Bluetooth-гүйгээр радарын симулятор

Гараар radar/detections топик руу JSON илгээж, радар дээр blip чиглэлээ өөрчлөх:

mosquitto_pub -h localhost -t "radar/detections" -m '{"datetime":"2026-09-10 14:30:00","lat":47.9185,"long":106.9177,"altitude":500,"speed":120,"direction":45,"object_name":"target-01"}'
