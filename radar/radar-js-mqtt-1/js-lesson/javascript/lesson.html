Хичээл 02 — JavaScript

Аппын цөм: төлөв, DOM, мэдээ, цаг

Бүх логик radar.html доторх <script> блоконд байна. Хамгийн чухал шийдэл нь төлөвийг нэг объектод хадгалах юм.

1. Төлөв (state) объект

const state = {
  mapTheme: 'dark',
  mapProvider: 'carto',
  customColor: '#00ff00',
  center: { lat: 47.91856696684756, lon: 106.91779462330955 },
  sweepAngle: 0,
  currentPage: 1,
  perPage: 20,
  mqttConnected: false,
  mqttClient: null,
  detections: [],
  robots: {},
  robotCfg: {},
  colors: { green: '#0f0', red: '#f33', blue: '#39f', custom: '#00ff00' },
};

Сайн тал: нэг л газар бүх өгөгдөл; өөр өөр функцууд state.xxx уншиж/бичиж, нийтлэг төлөвийг хуваалцана.

2. DOM ажиллагаа

Өөрчлөлтийг гар аргаар UI-д хуулдаг (renderTable() гэх мэт):

function renderTable() {
  const tbody = document.getElementById('tableBody');
  const total = state.detections.length;
  const totalPages = Math.max(1, Math.ceil(total / state.perPage));
  ...
  tbody.innerHTML = '';
  page.forEach((d, i) => {
    const tr = document.createElement('tr');
    if (i === 0) tr.className = 'new-detection';
    tr.innerHTML = `<td>${start + i + 1}</td><td>${d.datetime}</td>...`;
    tbody.appendChild(tr);
  });
  renderPagination(totalPages);
}

Темплейт string-д (`...${...}`) хувьсагч шууд орлуулдаг. Гэхдээ хэрэглэгчийн оруулсан текстийг орлуулахдаа болгоомжтой — XSS-ээс хамгаалахын тулд зөвшөөрөгдсөн тэмдэгтийг шүүж байгаа (робот нэр → sanitizeName()).

3. Мэдээ хүлээн авах (MQTT callback)

state.mqttClient.onMessageArrived = function(msg) {
  const t = msg.destinationName;
  if (t.indexOf('robots/') === 0) { handleRobotMsg(t, msg.payloadString); return; }
  try {
    const data = JSON.parse(msg.payloadString);   // текст → объект
    addDetection(data);
  } catch (e) { log('Invalid message: ' + e.message); }
};

Хэрэв топик robots/ гэж эхэлбэл роботын зам руу, эс бөгөөс radar detection гэж үзнэ.

4. Радар эргэлтийн loop

Canvas радар нь requestAnimationFrame ашиглан секундэд ~60 удаа зурагддаг:

function step(t) {
  if (state.mapTheme === 'dark' || state.mapTheme === 'black') {
    state.sweepAngle = (state.sweepAngle + 0.8) % 360;
    drawRadarOverlay();   // цацраг үүсгэх
  }
  requestAnimationFrame(step);
}
requestAnimationFrame(step);

5. Тохиргоог хадгалах (localStorage)

function saveCfg() {
  localStorage.setItem('radar_cfg', JSON.stringify(state));
}
function loadCfg() {
  try {
    const c = JSON.parse(localStorage.getItem('radar_cfg'));
    if (c) Object.assign(state, c);
  } catch (e) { /* эхний удаа */ }
}

Хуудас revise-болгоход тохиргоо алга болдоггүй. Роботуудын хувьд radar_robot_cfg тусдаа ключ хэрэглэдэг.

6. Үйл явдал ба товч

  • onclick HTML атрибут: <button onclick="connectMqtt()">
  • Form submit-д return false, эсвэл event.preventDefault()
  • Map хөдөлгөөн: map.on('moveend', function(){...}) — зураг дээр хүрэхэд төвийг шинэчилнэ

Дасгал
