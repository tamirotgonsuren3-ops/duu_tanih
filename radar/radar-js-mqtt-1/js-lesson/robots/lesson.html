Хичээл 07 — Robots дэд систем

Роботууд: status, радар, тохиргоо, камер

Физик робот бүр: телефон + Arduino + HLK-LD2415H радар (OTG USB). Телефон нь MQTT-ээр robots/<name>/status болон robots/<name>/radar-ыг нийтэлж, вэб апп захиалдаг.

1. Хүлээн авах, хадгалах

const state = { ..., robots: {}, robotCfg: {} };

function handleRobotMsg(topic, payload) {
  const m = t.split('/');                  // ['robots','robot-1','status']
  const name = m[1];
  const kind = m[2];
  const data = JSON.parse(payload);
  const r = ensureRobot(name);             // шинэ робот үүсгэх юм
  r.lastSeen = Date.now();
  if (kind === 'status') Object.assign(r, data);   // GPS, батарея гэх мэт
  else { r.lastRadar = data; r.blips = radarToBlips(data); }
  renderRobotsTables();
  drawRobotOnMapSafe(r);                   // зургуудаа (sig) давхарт нь шалган зурна
}

ensureRobot(name) нь state.robots[name] байхгүй бол тохиргоогоор (default range 200m, ring 4, color green, useGps true) шинээр үүсгэдэг:

function ensureRobot(name) {
  if (state.robots[name]) return state.robots[name];
  const cfg = state.robotCfg[name] || {};
  const r = Object.assign({ name }, defaultRobot, cfg);
  state.robots[name] = r;
  return r;
}

2. Хадгалалт (localStorage)

const cfgKey = 'radar_robot_cfg';
function saveRobotCfg() {
  localStorage.setItem(cfgKey, JSON.stringify(state.robotCfg));
}
function loadRobotCfg() {
  try { state.robotCfg = JSON.parse(localStorage.getItem(cfgKey)) || {}; }
  catch (e) { state.robotCfg = {}; }
}

Хуудас дахин ачаалагдсаны дараа роботууд ижил тохиргоотой байна. robots/+/radar ба robots/+/status топикуудыг onSuccess дотор захиална.

3. Хүснэгтүүд + online/offline

Гурван байршил байна: Home (заах хүснэгт), Robots хуудас (шиг хүснэгт), sidebar summary. Ойролцоогоор online гэж тооцоолдог:

function isRobotOnline(r) {
  return (Date.now() - r.lastSeen) < 12000;   // 12 секундээс дээшгүй
}

Тогтмол setInterval(tickRobots, 5000) нь хүснэгтүүдийг дахин зурдаг. Мөр бүр дээр:

4. Мап дээрх роботын радар

Робот бүр Leaflet дээр хүрээлэгдсэн тойрогтой:

function drawRobotOnMap(r) {
  const cols = makeColorSet(r.color);
  const group = L.layerGroup();
  group.addLayer(L.circle([r.lat, r.lon], { radius: r.rangeM, color: r.color, fill: false }));
  // rings (ялга өнгийн цагирагууд)
  for (let i = 1; i <= r.rings; i++)
    group.addLayer(L.circle([r.lat, r.lon], { radius: r.rangeM * i / r.rings, color: cols.dimmer, dashArray: '4 6' }));
  // heading (машигийн явах чиглэл)
  if (r.heading != null) {
    const dest = llDest(r.lat, r.lon, r.heading, r.rangeM * 0.8);
    group.addLayer(L.polyline([[r.lat, r.lon], dest], { color: r.color }));
  }
  // blips: LL->хүрээний доторх цэгүүд (LD2415H зай + heading)
  (r.blips || []).forEach(b => {
    group.addLayer(L.circleMarker([b.lat, b.lon], { radius: 6, color: 'yellow', fillColor: 'yellow', fillOpacity: 0.9 }));
  });
  group.addTo(map);
  r.layers = { group };
}

5. Тохиргооны модаль

Мөр дээр дархад openRobotConfig(name) нь модаль нээгээд өнөөгийн утгуудыг дүүргэнэ:

  • Нэр (rename — уншихыг нарийн: ижил нэртэй робот байвал зөвшөөрөхгүй)
  • Хүрээ (m), цагирагууд, өнгө (color picker), useGps (мап дахь GPS / manual)
  • Heading, "Center map here", Camera view

Хадгалах saveRobotConfig() нь state.robotCfg[name] шинэчилж, localStorage-д хадгалаад, мап дээр дахин зурна. removeRobot(name) нь мап давхаргуудыг устгаж, хүснэгтүүдээс хасна (confirm асууна).

6. Камер viewer

Роботын камерыг live харна: <img src="/cam/<name>/mjpeg">. Энэ нь серверийн MJPEG stream-ээ без обновления хэлбэрээр харж болно:

function openCam(name) {
  document.getElementById('camImg').src = '/cam/' + encodeURIComponent(name) + '/mjpeg';
  document.getElementById('camTitle').textContent = 'Camera — ' + name;
  document.getElementById('camOverlay').style.display = 'flex';
}
Роботын GPS ирвэл useGps-ээр мап дээрх байрлал автоматаар шинэчлэгдэнэ. GPS-гүй бол (гадаа) manual байрлалыг модульд оруулна.
