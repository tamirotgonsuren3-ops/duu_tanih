Хичээл 08 — Arduino + LD2415H радар

UART холболт, пакетын формат, CRC16, програм

Роботын радар нь HLK-LD2415H 24GHz mmWave радар модуль. Энэ нь UART (serial) интерфэйсээр мэдээлэл өгдөг. Arduino модуль болон телефон хоёрын хооронд гүүр болж ажиллана.

1. Угсралт (wiring)

ArduinoLD2415H
Pin D2 (RX)TX
Pin D3 (TX)RX
5V5V/VIN
GNDGND

Arduino SoftwareSerial (D2/D3) эсвэл API-ийн Serial1 ашиглана. Телефон OTG кабелээр Arduino-ийн USB-д холбогдож, Serial (115200 8N1) -ийг харьцуулдаг.

#define RADAR_TX 3   // D3 pin -> LD2415H RX
#define RADAR_RX 2   // D2 pin <- LD2415H TX
#include <SoftwareSerial.h>
SoftwareSerial Radar(RADAR_RX, RADAR_TX);

2. LD2415H пакетын формат

LD2415H нь тогтмол пакетүүдийг UART-аар илгээдэг:

╔═══════════════════════════════════════════════════════╗
║ Header:  0xF4 0xF3 0xF2 0xF1                           ║
║ DataInt: 12 + 6×N   (N = target тоо)  [LE 16-bit]      ║
║ Data:    ...                                            ║
║ Checksum: CRC16 (Modbus шиг: poly 0x1021, init 0xFFFF) ║
║ Tail:    0xF8 0xF7 0xF6 0xF5                            ║
╚═══════════════════════════════════════════════════════╝

Data дотор: state (0=юу ч байхгүй, 1=хөдөлгөөнт, 2=тогтмол), distance, energy, дараа нь гол буудлын бүх target-ийн gate/type/distance/energy.

3. Пакет задлах

Arduino буфер руу byte-уудыг цуглуулаад, header-ээс олж, CRC шалгаж, бүрэн рамнаас өгөгдлийг авдаг:

const uint8_t HEADER[4] = {0xF4,0xF3,0xF2,0xF1};
const uint8_t TAIL[4]   = {0xF8,0xF7,0xF6,0xF5};

void parseRadar() {
  for (int i = 0; i <= idx - 14; i++) {
    if (memcmp(buf + i, HEADER, 4) != 0) continue;
    uint16_t len = buf[i+4] | (buf[i+5] << 8);      // Little-Endian
    if (i + 4 + len + 4 > idx) return;               // харах биш
    uint16_t crcCalc = crc16(buf + i + 6, len - 2);
    uint16_t crcGot  = (buf[i+6+len-2]) | (buf[i+6+len-1] << 8);
    if (crcCalc != crcGot) return;                    // муу пакет
    // ... state, dist, ena, targets уншина ...
  }
}

uint16_t crc16(const uint8_t* d, int n) {
  uint16_t crc = 0xFFFF;
  for (int i = 0; i < n; i++) {
    crc ^= d[i];
    for (int b = 0; b < 8; b++)
      crc = (crc & 1) ? (crc >> 1) ^ 0x1021 : (crc >> 1);
  }
  return crc;
}

4. JSON мөр гаргах (телефон руу)

Arduino нь илрүүлэлтийг энгийн JSON мөр болгон Serial руу бичнэ:

Serial.print(F("RADAR {"));
Serial.print(F("\"state\":"));   Serial.print(state);
Serial.print(F(",\"dist\":"));   Serial.print(dist);
Serial.print(F(",\"ena\":"));    Serial.print(ena);
Serial.print(F(",\"targets\":["));
for (int i = 0; i < targetCount; i++) {
  if (i) Serial.print(',');
  Serial.print(F("{\"g\":"));    Serial.print(gs[i]);
  Serial.print(F(",\"t\":"));    Serial.print(ts[i]);
  Serial.print(F(",\"d\":"));    Serial.print(ds[i]);
  Serial.print(F(",\"e\":"));    Serial.print(es[i]);
  Serial.print('}');
}
Serial.println(F("]}"));

Телепонны USB-serial сонсогч энэ мөрийг барьж, RADAR угтвараар таньдаг. Мөр выпуклаад, төсөөллийн утгуудыг түр зуур үүсгэдэг.

Хуурай туршилтад (hardware-гүй) WEB Serial monitor-ээс ч гэсэн гаргах боломжтой. LD2415H-ийн бодит мэдээлэл авахын тулд hardware холбох хэрэгтэй.

Дасгал

  • Симуляцитай үед RADAR мөрний dist-г өөрчилөөд вэб аппны роботын хүснэгтэд яаж тусгагддагийг хар.
  • CRC алдаатай пакет ирэхэд юу болохыг судлахын тулд санаатайгаар byte буруу илгээ.
