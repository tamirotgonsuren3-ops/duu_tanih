Хичээл 01 — HTML & CSS

Хуудасны бүтэц, байрлал, хэв маяг

Апп нь нэг ерөнхий radar.html файл — HTML, CSS, JavaScript бүгд дотор нь. Энэ нь самбар (sidebar) + үндсэн хэсэг (main) гэсэн хоёр хэсэгтэй, зүүн самбар нь удирдлага, баруун тал нь газрын зураг/радар.

Үндсэн HTML бүтэц

Бүх зүйл <html>,<body> 100% өндөртэй, дотоод нь #app flex-based хэвтээ хуваагдана:

<body>
  <div id="app">                              <!-- бүх дэлгэц -->
    <div id="sidebar">                       <!-- зүүн 340px хяналтын самбар -->
      <div class="sidebar-header">...</div>  <!-- Гарчиг/лого -->
      <div class="nav-tabs">                  <!-- Home | Robots -->
        <div class="nav-tab active" onclick="switchPage('home')">Home</div>
        <div class="nav-tab" onclick="switchPage('robots')">Robots</div>
      </div>
      <div class="section">...</div>         <!-- MQTT тохиргоо -->
      <div class="section">...</div>         <!-- Төв/параметер -->
      <div class="section">...</div>         <!-- Зураглал/өнгө -->
      <div id="sidebar-footer">               <!-- ёроолд: JS Lesson линк -->
        <button onclick="openLesson()">JS Lesson</button>
      </div>
    </div>
    <div id="main">                           <!-- баруун хэсэг -->
      <div id="homeView">                     <!-- зураг + радар, дараа нь хүснэгт -->
        <div id="radar-container">            <!-- бүтэн 100vh өндөр -->
          <div id="map"></div>
          <canvas id="radarOverlay"></canvas>
        </div>
        <div id="bottom-stack">              <!-- historical + robots таблицууд -->
          ...
        </div>
      </div>
    </div>
  </div>
</body>

Хуудасны scroll-ийн логик:

  • html,body{height:100%;overflow:hidden;} — хуудас өөрөө scroll-дохгүй;
  • #sidebar нь overflow-y:auto — зөвхөн самбар scroll-доно;
  • #homeView{overflow-y:auto} ба #radar-container{height:100vh} — радар дэлгэцийг бүтэн эзэлнэ, доорх хүснэгтүүд рүү scroll хийгээд харна.

CSS-ийн гол зарчим

Тем нь хар (#0a0a0a) дэвсгэр + ногоон (#0f0) акцент. Энэ хоёр өнгийг ашиглахад радарын мэдрэмж гарна.

СонгогчҮүрэг
#appБүх дэлгэц: display:flex, хэвтээ домог
#sidebar340px тогтмол өргөн, зүүн талд
#mainflex:1 — үлдсэн бүх өргөнийг авна
#radar-containerheight:100vh — радар бүтэн дэлгэц
.fieldИнпут бүрийн гадна талбай (label + input)
.btn-primaryНогоон гол товч (Connect/Simulate)
#modalOverlayТогтмол position:fixed бүрхүүл, төвд modal

Модаль цонх

Тохиргооны цонхнууд нэг нийтлэг загвартай: бүрхүүл #modalOverlay, дотор нь .modal. Харагдах/нуугдахыг JavaScript display:flex ↔ none шилжүүлдэг:

#modalOverlay{position:fixed;inset:0;background:rgba(0,0,0,0.75);
  display:none;align-items:center;justify-content:center;z-index:2000;}
.modal{background:#111;border:1px solid #333;border-radius:8px;
  width:min(560px,94vw);max-height:90vh;overflow:auto;padding:20px;}

Хичээлийн модаль

Зүүн самбарын ёроолын JS Lesson товч нь апп дотор <iframe> ачаалж, хичээлийг алдалгүй харна:

<div id="lessonOverlay">
  <div class="modal modal-wide">
    <iframe id="lessonFrame" src="js-lesson/index.html"></iframe>
  </div>
</div>

ижил origin-тэй тул хичээлийн доторх "Хаах" товч parent.closeLesson() гэж дээд цонхны функцийг дуудаж чадна.

Өөрчлөл хийж үзэх

  • radar.html доторх өнгөний утгуудыг өөрчил: #0f0 → #0ff гэх мэт.
  • ---аар шинэ товч нэмээд onclick өг (жишээ: "Export").
  • Самбарын өргөнийг #sidebar{width:340px} → 380px болго.
