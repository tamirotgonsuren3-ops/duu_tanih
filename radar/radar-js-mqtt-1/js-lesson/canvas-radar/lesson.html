Хичээл 05 — HTML5 Canvas радар

Радар overlay, эргэлт, координатын тооцоо

Радар нь газрын зургийн дээгүүр тунгалаг canvas-аар зурагддаг. Canvas нь төв рүү төвлөрсөн тойрог, шугам сүлжээ, хөдөлгөөнт цацраг, blip-уудыг 60fps хурдтайгаар зурна.

1. Canvas ба масштаб (devicePixelRatio)

const radarCanvas = document.getElementById('radarOverlay');
const rctx = radarCanvas.getContext('2d');

function resizeRadar() {
  const dpr = window.devicePixelRatio || 1;
  radarCanvas.width  = radarCanvas.clientWidth  * dpr;
  radarCanvas.height = radarCanvas.clientHeight * dpr;
  rctx.setTransform(dpr, 0, 0, dpr, 0, 0);
}
window.addEventListener('resize', resizeRadar);

Энэ нь өндөр масштабтай дэлгэц дээр ч зураг тод (хурц) хэвээр байх баталгаа.

Радарын хүрээ квadrad хэлбэртэй контейнерийн төвд, хамгийн жижиг талын 50%-аас 20px-ээр дотогшлод.

3. Хөдөлгөөнт цацраг (sweep)

function step(t) {
  if (state.mapTheme === 'dark' || state.mapTheme === 'black') {
    state.sweepAngle = (state.sweepAngle + 0.8) % 360;
    drawRadarOverlay();
  }
  requestAnimationFrame(step);
}

Өнцөг бүр кадр тутамд 0.8°-ээр нэмэгдэнэ (≈ 2.6 сек/эргэлт). drawRadarOverlay() нь цацрагыг сүүлийн sweepLength градусаар сүүдрэх (fade) болгон зурдаг:

const sweepStart = (state.sweepAngle - 90 + 360) % 360;   // 90°-ийн цацраг
ctx.beginPath();
ctx.moveTo(cx, cy);
ctx.arc(cx, cy, radius, deg(rad - sweepLength), deg(rad));
ctx.closePath();
ctx.fillStyle = 'rgba(0,255,0,0.25)';   // сүүдрийн давхарга
ctx.fill();

5. Зайны хувиргалт (px руу)

Радар дээр blip-ын пиксель байрлал = зай/макс хүрээ × радиус:

function distToPx(meters) {
  return meters / state.maxRangeM * (Math.min(w,h) / 2 - 20);
}

Тодорхой чиглэлд (бөмбөрцөг координат) blip зурхайн хувьд:

function llDest(lat, lon, bearingDeg, distM) {
  const R = 6371000;               // Дэлхийн радиус (m)
  const d = distM / R;             // өнцгийн зай
  const brng = bearingDeg * Math.PI / 180;
  const la1 = lat * Math.PI / 180, lo1 = lon * Math.PI / 180;
  const la2 = Math.asin(Math.sin(la1)*Math.cos(d) + Math.cos(la1)*Math.sin(d)*Math.cos(brng));
  const lo2 = lo1 + Math.atan2(Math.sin(brng)*Math.sin(d)*Math.cos(la1),
                               Math.cos(d) - Math.sin(la1)*Math.sin(la2));
  return [la2*180/Math.PI, lo2*180/Math.PI];
}

Энэ функциум роботын радар blip (зай + толгой чиглэл) ашиглан байрлалыг тооцож, Leaflet дээр тэмдэглэдэг. LD2415H нь зай л өгдөг тул роботын heading чиглэлд dist метрийн зайд blip зурна.

6. Blip (объект цэг)

state.blips.forEach(b => {
  const angle = b.direction - 90;   // хойд/болор
  const rad = (angle * Math.PI) / 180;
  const r = distToPx(b.distance);
  const x = cx + Math.cos(rad) * r;
  const y = cy + Math.sin(rad) * r;
  ctx.beginPath();
  ctx.arc(x, y, 3, 0, 2 * Math.PI);
  ctx.fillStyle = b.color;
  ctx.shadowBlur = 6;
  ctx.shadowColor = b.color;
  ctx.fill();
});

Blip бүсмөргүй фейд болдог: state.blips нь state.now - b.ts < 5000 байвал зурагддаг, өнгө нь theme дагуу:

const base = state.colors[state.colorTheme];
const cols = makeColorSet(base);   // {base, brighter, dimmer, bg}
Радарын параметрүүд (maxRangeM, rings, sweepLength, өнгө) sidebar дээр өөрчлөгддөг — өөрчлөлт хийгээд шууд харна.

Дасгал

  • sweepLength утгыг өөрчилөөд цацраг өргөрөхийг хар.
  • Тойргийн өнгийг өөрийн сонгосон өнгөөр (жишээ: #ff0) өөрчил.
  • distToPx дээр maxRangeM ашиглахгүй бол юу болохыг бод.
